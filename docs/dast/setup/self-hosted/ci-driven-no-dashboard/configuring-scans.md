# Configuring CI-driven scans with no dashboard

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 You can configure CI-driven scans with no dashboard to use more advanced features of Burp Scanner, such as application logins. To do this, you use a configuration file.

 The configuration file enables you to define the [site settings](https://portswigger.net/burp/documentation/dast/user-guide/managing-your-sites/site-settings) and the [scan configurations](https://portswigger.net/burp/documentation/scanner/scan-configurations) that Burp Scanner uses to perform a scan. The file is in YAML format.
