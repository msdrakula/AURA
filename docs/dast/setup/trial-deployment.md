Self-hosted

 Use this tutorial to set up a trial self-hosted instance of Burp Suite DAST. We show you how to download and install the software, and perform your first scan of a site.


1.  [Install with the default options](https://portswigger.net/burp/documentation/dast/setup/trial-deployment/install-with-default-options)
1.  [Run your first scan](https://portswigger.net/burp/documentation/dast/setup/trial-deployment/run-your-first-scan)
1.  [Analyze your scan results](https://portswigger.net/burp/documentation/dast/setup/trial-deployment/analyze-your-scan-results)
1.  [Next steps after installation](https://portswigger.net/burp/documentation/dast/setup/what-next)

 Alternatively, if you're interested in a trial of a Cloud instance of Burp Suite DAST, please contact us through our [trial page](https://portswigger.net/burp/dast/trial).


#### Note

- For information on installing a standard instance for production use, including configuring an external database and scanning machines, see [Prerequisites for a standard installation](https://portswigger.net/burp/documentation/dast/setup/self-hosted/standard/standard-install-prerequisites).
- For information on deploying to Kubernetes using a Helm chart, see [Deploying Burp Suite DAST to Kubernetes](https://portswigger.net/burp/documentation/dast/setup/self-hosted/kubernetes).
- We recommend that you view the system requirements before attempting to install. See [Burp Suite DAST system requirements](https://portswigger.net/burp/documentation/dast/setup/self-hosted/system-req-overview) for more information.
