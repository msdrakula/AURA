# Managing your sites

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

![ps-hosted-lozenge](https://portswigger.net/burp/documentation/images/icons/burp-icon-enterprise.svg)

Cloud

![self-hosted-lozenge](https://portswigger.net/burp/documentation/images/icons/person.svg)

Self-hosted

 In Burp Suite DAST, the term "site" refers to either a web app or API that you want to scan.


 To scan a site, you first need to add it to Burp Suite DAST. Most data and configuration options in Burp Suite DAST are managed on a per-site basis. Adding detailed information about your sites unlocks the full potential of Burp Suite DAST's analytics features, enabling you to track issues with your site more effectively over time.


-

To add a site for scanning web apps, see [Scanning web apps](https://portswigger.net/burp/documentation/dast/user-guide/scanning-web-apps)
-

To add a site for scanning APIs, see [Scanning APIs](https://portswigger.net/burp/documentation/dast/user-guide/scanning-apis)
