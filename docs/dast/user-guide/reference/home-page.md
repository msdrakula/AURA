# Home page

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 When you first log in to Burp Suite DAST, you are presented with the home page dashboard. Initially, this will be a fairly empty screen. Once you have run a few scans, the home page contains summarized information about all sites that you have configured.


## Dashboard

 The dashboard shows various charts containing the current status and [trends over time](https://portswigger.net/burp/documentation/dast/user-guide/work-with-scan-results/track-issues). These include the current issues, most vulnerable sites, most serious vulnerabilities, issue counts and resolution over time, and recent scans.

## Issues

 The Issues tab shows an aggregated view of all issues reported in the latest scans of all sites that are configured.

 You can expand an issue type to see the addresses of the relevant pages. You can also download the issues shown as a CSV file. For more information, see [Downloading issues as a CSV file](https://portswigger.net/burp/documentation/dast/user-guide/work-with-scan-results/managing-issues#downloading-issues-as-a-csv-file).
