# Configuring site and scan data settings

**Last updated: ** September 3, 2026

Self-hosted

 You can configure Burp Suite DAST to create new sites for API-generated scans. You can also change the criteria that identify issues as new, and manage whether old scans are automatically deleted.


 To configure how your site and scan data is managed:


1.
 From the settings menu , select **Site and scan data**.

1.

![self-hosted-lozenge](https://portswigger.net/burp/documentation/images/icons/person.svg)

Self-hosted To automatically create sites for API-generated scans, select **Display sites generated by the REST API**.

1.

 Set how long you want to keep old scans. You can specify a time from 1 day up to 5 years under **Automatically delete old scans**.


#### Note

 Burp Suite DAST always keeps the most recent scan, even if it's older than the defined threshold.

1.
 To change which issues are identified as new, set **Scan Deltas** to **Anywhere on the site** or **At the same URL**.
