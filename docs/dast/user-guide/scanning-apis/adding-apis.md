 You can add APIs to Burp Suite DAST by connecting integrations or by uploading API definitions directly.

-

[Discovering APIs from integrations](https://portswigger.net/burp/documentation/dast/user-guide/scanning-apis/adding-apis/api-integrations) - Connect third-party services to automatically discover APIs deployed in your environment.
-

[Adding a single API](https://portswigger.net/burp/documentation/dast/user-guide/scanning-apis/adding-apis/adding-single-api) - Add one API at a time by uploading a file or providing a URL.
-

[Bulk uploading APIs](https://portswigger.net/burp/documentation/dast/user-guide/scanning-apis/adding-apis/bulk-uploading-apis) - Add multiple APIs in a single operation.
