Self-hosted

 You can manage authentication centrally using a single sign-on (SSO) solution. Burp Suite DAST supports a number of SSO options, as well as SCIM.


#### Note

 Before you enable SSO, we recommend you create a backup local admin user. For more information, see [Adding local users](https://portswigger.net/burp/documentation/dast/user-guide/users-and-permissions/adding-local-users).


 To learn how to enable SSO for Burp Suite DAST, see the documentation for your setup:
