# Setting up Burp Suite DAST

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 Depending on your subscription, you have several different options for hosting your Burp Suite DAST instance.

-
 If you haven't purchased a subscription yet, see [Burp Suite DAST: Pricing](https://portswigger.net/burp/dast/pricing).

-
 If you want to set up a Cloud instance of Burp Suite DAST, see [Setting up a Cloud instance](https://portswigger.net/burp/documentation/dast/setup/cloud).

-
 If you want to migrate from your Linux self-hosted instance, see [Migrating from Linux to Cloud](https://portswigger.net/burp/documentation/dast/setup/migrate-linux-to-cloud)
-
 If you want to migrate from your Windows self-hosted instance, see [Migrating from Windows to Cloud](https://portswigger.net/burp/documentation/dast/setup/migrate-windows-to-cloud)
-
 If you want to deploy a self-hosted instance of Burp Suite DAST, see [Setting up a self-hosted instance](https://portswigger.net/burp/documentation/dast/setup/self-hosted).

-
 If you've already set up Burp Suite DAST and you want to learn more about how to use it, see the [User guide](https://portswigger.net/burp/documentation/dast/user-guide).
