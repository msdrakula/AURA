# UI settings

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 The **User interface** settings enable you to configure aspects of Burp Suite's appearance. From here, you can change settings for:


- [Side panel](https://portswigger.net/burp/documentation/desktop/settings/ui/side-panel) - Configure the layout of the side panel and the Inspector widgets.
- [Message editor](https://portswigger.net/burp/documentation/desktop/settings/ui/message-editor) - Configure the layout of the message editor and how messages are displayed.
- [Hotkeys](https://portswigger.net/burp/documentation/desktop/settings/ui/hotkeys) - Configure hotkey shortcuts for common actions.
- [Displays](https://portswigger.net/burp/documentation/desktop/settings/ui/display) - Configure Burp Suite's theme and font size, and the tabs displayed on the menu.
