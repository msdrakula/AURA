# AI settings

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 Burp AI only runs if you explicitly activate it. The **AI settings** page provides an additional safeguard to prevent you from accidentally using AI.


 Select **Disable AI features** to disable all AI communication, including AI credit balance checks. Disabling AI features also turns off Burp AT. When AI features are disabled, any AI-related options are grayed out in Burp and cannot be selected.
