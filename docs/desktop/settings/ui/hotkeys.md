# Hotkey settings

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 The **Hotkey** settings enable you to configure hotkeys for common commands in Burp. Some hotkeys are configured by default, while others can be added manually.


To add or edit a hotkey:

1. Go to **Settings > User interface > Hotkeys**.
1. Double-click the command that you want to configure.
1. Press the key combination that you want to assign.
1. Click **Apply**.

 When creating or using hotkeys, keep the following in mind:


- All hotkeys must use the `Cmd` / `Ctrl` key.
- You can use modifiers such as `Shift`.
- If you're using Windows, avoid assigning `Ctrl+Alt` to hotkeys you'll use while editing text. On
 some installations, `Ctrl+Alt` is treated as `AltGr`, which may cause characters to
 appear when the hotkey is pressed.

 Related pages


 You can access all commands listed in the Hotkeys table directly through the command palette. For more information, see
 the [Command palette](https://portswigger.net/burp/documentation/desktop/tools/command-palette) documentation.


 The **Hotkeys** settings are user settings. They apply to all installations of Burp on your machine.
