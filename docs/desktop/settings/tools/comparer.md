# Comparer settings

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 The **Comparer** page in the **Settings** dialog enables you to customize the behavior of Comparer.


## Sync Comparer results view

 This setting controls whether panels in new Comparer results windows stay in sync by default.
