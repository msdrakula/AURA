# Network settings

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 The **Network** section in the **Settings** dialog enables you to configure:


- [Connections](https://portswigger.net/burp/documentation/desktop/settings/network/connections) - General settings defining how Burp handles network traffic.
- [TLS](https://portswigger.net/burp/documentation/desktop/settings/network/tls) - Settings related to the TLS protocols and certificates that Burp uses.
- [HTTP](https://portswigger.net/burp/documentation/desktop/settings/network/http) - Settings controlling how Burp processes HTTP traffic.
- [DNS](https://portswigger.net/burp/documentation/desktop/settings/network/dns) - Settings for resolving domain names to IP addresses.
