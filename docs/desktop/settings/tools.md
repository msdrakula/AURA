# Tools settings

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 The **Tools** section in the **Settings** dialog contains settings that apply to individual tools within Burp Suite. From here, you can change settings for:


- [Proxy](https://portswigger.net/burp/documentation/desktop/settings/tools/proxy).
- [Intruder](https://portswigger.net/burp/documentation/desktop/settings/tools/intruder).
- [Repeater](https://portswigger.net/burp/documentation/desktop/settings/tools/repeater).
- [Comparer](https://portswigger.net/burp/documentation/desktop/settings/tools/comparer).
- [Sequencer](https://portswigger.net/burp/documentation/desktop/settings/tools/sequencer).
- [Burp's browser](https://portswigger.net/burp/documentation/desktop/settings/tools/burps-browser).
