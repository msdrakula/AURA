# Burp Suite tools

-

**Last updated: ** September 3, 2026
-

**Read time: ** 2 Minutes

 Burp Suite contains various tools for performing different testing tasks. The tools operate effectively together, and you can pass interesting requests between tools as your work progresses, to carry out different actions.


#### Read more

-  **[Dashboard](https://portswigger.net/burp/documentation/desktop/tools/dashboard)** - The **Dashboard** tab provides a central location for monitoring and controlling all of the automated tasks in your project, such as vulnerability scans or live tasks.

-  **[Target](https://portswigger.net/burp/documentation/desktop/tools/target)** - This tool contains detailed information about your target applications, and lets you drive the process of testing for vulnerabilities.

-  **[Burp's browser](https://portswigger.net/burp/documentation/desktop/tools/burps-browser)** - This browser is preconfigured to work with the full functionality of Burp Suite right out of the box.

-  **[Proxy](https://portswigger.net/burp/documentation/desktop/tools/proxy)** - This is an intercepting web proxy that operates as a man-in-the-middle between the end browser and the target web application. It lets you intercept, inspect and modify the raw traffic passing in both directions.

-  **[Scanner](https://portswigger.net/burp/documentation/scanner)** Professional
 - This is an advanced web vulnerability scanner, which can automatically crawl content and audit for numerous types of vulnerabilities.

-  **[Intruder](https://portswigger.net/burp/documentation/desktop/tools/intruder)** - This is a powerful tool for carrying out automated customized attacks against web applications. It is highly configurable and can be used to perform a wide range of tasks to make your testing faster and more effective.

-  **[Repeater](https://portswigger.net/burp/documentation/desktop/tools/repeater)** - This is a tool for manually manipulating and resending individual messages, and analyzing the application's responses.

-  **[Sequencer](https://portswigger.net/burp/documentation/desktop/tools/sequencer)** - This is a sophisticated tool for analyzing the quality of randomness in an application's session tokens or other important data items that are intended to be unpredictable.

-  **[Decoder](https://portswigger.net/burp/documentation/desktop/tools/decoder)** - This is a useful tool for performing manual or automated decoding and encoding of application data.

-  **[Comparer](https://portswigger.net/burp/documentation/desktop/tools/comparer)** - This is a handy utility for performing a visual "diff" between any two items of data, such as pairs of similar HTTP messages.

-  **[Logger](https://portswigger.net/burp/documentation/desktop/tools/logger)** - This is a tool for recording and analyzing HTTP traffic that Burp Suite generates.

-  **[Inspector](https://portswigger.net/burp/documentation/desktop/tools/inspector)** - This provides some useful features for analyzing and editing HTTP and WebSockets messages.

-  **[Collaborator](https://portswigger.net/burp/documentation/desktop/tools/collaborator)** Professional
 - This is a manual tool for identifying out-of-band vulnerabilities.

-  **[DOM Invader](https://portswigger.net/burp/documentation/desktop/tools/dom-invader)** - This is a tool for finding [DOM XSS](https://portswigger.net/web-security/cross-site-scripting/dom-based) vulnerabilities.

-  **[Clickbandit](https://portswigger.net/burp/documentation/desktop/tools/clickbandit)** - This is a tool for generating Clickjacking attacks.

-  **[Message editor](https://portswigger.net/burp/documentation/desktop/tools/message-editor)** - This is a tool for viewing and editing HTTP requests and responses throughout Burp.

-  **[Engagement tools](https://portswigger.net/burp/documentation/desktop/tools/engagement-tools)** Professional - Configure various engagement-related tasks.

-  **[Search](https://portswigger.net/burp/documentation/desktop/tools/search)** - This is a tool for performing searches in Burp Suite.

-  **[Command palette](https://portswigger.net/burp/documentation/desktop/tools/command-palette)** - This is a tool for quickly finding and running commands using your keyboard.

-  **[Infiltrator](https://portswigger.net/burp/documentation/desktop/tools/infiltrator)** - This is a tool for detecting whether Burp's input is passed to potentially unsafe APIs.

-  **[Organizer](https://portswigger.net/burp/documentation/desktop/tools/organizer)** - This is a tool for storing and annotating HTTP messages that you want to investigate later.

-  **[Context menu](https://portswigger.net/burp/documentation/desktop/tools/context-menu)** - The context menu provides quick access to a variety of tools and functions throughout Burp Suite.

-  **[Filter settings](https://portswigger.net/burp/documentation/desktop/tools/filter)** - These settings enable you to filter the messages that are shown in various Burp Suite tools.
