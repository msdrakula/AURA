# Download and install

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

### Step 1: Download

 Use the links below to download the latest version of Burp Suite Professional or Community Edition.


**Choose your software**  [Professional](https://portswigger.net/burp/releases/professional/latest) [Community Edition](https://portswigger.net/burp/releases/community/latest)

### Step 2: Install

 Run the installer and launch Burp Suite.


 When asked to select a project file and configuration, just click **Next** and then **Start Burp** to skip this for now.


#### Note

 If you're using Burp Suite Professional, enter your license key when prompted. If you don't have one already, you can [subscribe](https://portswigger.net/buy/pro) or
 [request a free trial](https://portswigger.net/burp/pro/trial).


### Step 3: Start exploring Burp Suite

 If you're completely new to Burp Suite, follow the rest of this tutorial for an interactive, guided tour of the core features.
