# Extension tutorials

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 These tutorials guide you through writing Burp Suite extensions using the [Montoya API](https://portswigger.github.io/burp-extensions-montoya-api/javadoc/burp/api/montoya/MontoyaApi.html).

 Whether you're new to extension development or want to enhance Burp with custom features, these detailed code guides cover common use cases and provide patterns you can adapt to your own work.

## Before you begin

 Make sure you've set up your extension development environment and created a Java class for your extension. For instructions, see
 [Setting up your extension development environment](https://portswigger.net/burp/documentation/desktop/extend-burp/extensions/creating/set-up).

 We also recommend completing our introductory tutorial, [Writing your first extension](https://portswigger.net/burp/documentation/desktop/extend-burp/extensions/creating/first-extension).
