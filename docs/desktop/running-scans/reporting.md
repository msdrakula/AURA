# Reporting scan results

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 After you use [Burp Scanner](https://portswigger.net/burp/documentation/desktop/running-scans) to scan a target, you can generate a report in HTML format for some or all of the issues found. This enables you to share the results with colleagues or clients. You can also export issue data in XML format, so that you can incorporate it into your own reporting systems.


 You can use the reporting wizard to generate and customize the output.
