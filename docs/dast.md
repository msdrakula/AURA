# Burp Suite DAST

-

**Last updated: ** September 3, 2026
-

**Read time: ** 1 Minute

 Burp Suite DAST is designed for automated scanning at any scale and enables integration with your software development processes.


-
 To learn how to set up Burp Suite DAST, see [Setting up Burp Suite DAST](https://portswigger.net/burp/documentation/dast/setup).

-
 Once you've set up Burp Suite DAST, you can onboard users from your organization and run your
 first scan. For more information about how to use Burp Suite DAST, [see the Burp Suite DAST user guide](https://portswigger.net/burp/documentation/dast/user-guide).


#### Warning

 Like any security testing software, Burp Suite contains functionality that can damage target systems. Testing for security flaws inherently involves interacting with targets in non-standard ways that can cause problems in some vulnerable targets. You should take due care when using Burp, read all documentation before use, back up target systems before testing, and not use Burp against any systems for which you are not authorized by the system owner, or for which the risk of damage is not accepted by you and the system owner.
